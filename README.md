# 📚 ReadBoost ID

**ReadBoost ID** is a mobile application for Android designed to increase interest and literacy skills in Indonesia through a more engaging, adaptive, and interactive reading experience. The app combines high-quality reading content with gamification elements to make learning fun.

## ✨ Key Features

- **Gamification**: Earn XP, maintain streaks, and climb the competitive leaderboard.
- **Adaptive Reading**: Content tailored to your reading level and interests.
- **Interactive Quizzes**: Test your knowledge after reading each article.
- **Admin Panel**: A robust CRUD system for administrators to manage literacy content.

## 🛠️ Technology Stack

- **Language**: Kotlin
- **Platform**: Android
- **Backend**: Firebase (Authentication, Real-time Database)
- **UI**: XML with Material Design components

## 📂 Project Structure

- `/app`: Main Android application source code.
- `/build.gradle.kts`: Project-level build configurations.
- `/google-services.json`: Firebase integration configuration.

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in **Android Studio**.
3. Sync Gradle and run the app on an emulator or physical device.
